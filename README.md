## 🚀 Key Features & Interactive Architecture Demos

1. **Interactive Agentforce AI Studio Simulator:**
   - Real-time conversational AI agent demonstrating Salesforce Agentforce runtime actions, topic triggers, CRM grounding, and guardrails.

2. **Salesforce Architecture Lab & Diagrammer:**
   - Interactive system architecture canvas modeling Multi-Org topologies, ERP middleware (MuleSoft/Kafka), and Salesforce Event Bus.

3. **Live REST Integration Testbench:**
   - Real-time mock runner for Composite REST APIs, OAuth 2.0 Web Server / JWT flows, and Bulk API 2.0 batch payloads.

4. **Service Cloud Case Console & Opportunity Kanban:**
   - Realistic Lightning Experience UI simulating high-volume case management, SLA countdowns, and drag-and-drop opportunity pipelines.

5. **Apex Enterprise Patterns & LWC Code Showcase:**
   - Deep-dive into Trigger Handler frameworks, `fflib` Selector & Domain layers, Batch/Queueable Apex, and Shadow DOM optimizations.

6. **Certification Verification Matrix:**
   - Official credentials with credential IDs, verification links, and skill taxonomy.

7. **Interactive Resume & PDF Generator:**
   - View, customize, and export ATS-friendly resume directly from the browser.

## 💻 Local Development

Clone the repository and install dependencies:

```bash
# Clone repository
git clone https://github.com/Suhas-P28/salesforce-developer-portfolio.git

# Navigate into project directory
cd salesforce-developer-portfolio

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:3000` (or `http://localhost:5173`) in your browser.

### Build for Production:
```bash
npm run build
```
